# Changelog

## 1.0.0
- **AWS Cedar Integration**: Advanced ABAC/RBAC policy engine support.
- **MCP Gateway**: Proxy any Model Context Protocol tool behind AgentGuard.
- **Fail-Closed Architecture**: Natively halt agent execution strictly on timeouts or unknown events.
- **Python SDK**: Universal decorators and framework-specific integrations (LangChain, CrewAI).
- **Persistent Hash Chain**: SQLite-backed cryptographic verification for audit ledgers.
- **JIT Approvals**: Pending human approvals perform just-in-time re-evaluations before execution to prevent race conditions.
- **Threat Detection Engine**: Deep context analysis preventing Prompt Injections and Sensitive Data Exfiltration.
- **Textual TUI**: Real-time terminal UI for monitoring and approving traffic.
